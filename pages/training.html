Пошаговые гайды

Изучите каждый модуль TeleBoost AI за 5 минут. От регистрации до первых продаж.

1

Быстрый старт

Регистрация, настройка аккаунта и запуск первого модуля за 5 минут.

Для новичков 5 мин
  1. Перейдите в Telegram-бот @teleboostai_bot и нажмите /start
  2. Следуйте инструкциям по регистрации — процесс занимает 30 секунд
  3. Откройте Mini App нажатием кнопки «Открыть панель»
  4. Добавьте первый Telegram-аккаунт через менеджер аккаунтов
  5. Запустите базовый парсинг для тестирования
2

Парсинг аудитории

Сбор целевой аудитории из каналов и групп с поведенческим анализом.

Парсинг AI
  1. Откройте модуль «Парсинг» на главной странице
  2. Выберите тип: Пользователи / Каналы / Сообщения / По ключам
  3. Введите ссылку на целевой канал или группу
  4. Укажите ключевые слова для фильтрации (опционально)
  5. Настройте лимит (рекомендуется 1000 для начала) и период
  6. Нажмите «Запустить парсинг» и дождитесь результатов
  7. Скачайте результаты в CSV или JSON для дальнейшего использования
3

Прогрев аккаунтов

Повышение trust-score аккаунтов перед активными действиями.

Безопасность Anti-Ban
  1. Добавьте аккаунты через менеджер аккаунтов
  2. Перейдите в модуль «Прогрев»
  3. Выберите AI-режим (рекомендуется «Средний»)
  4. Установите цель прогрева: 80% для обычной работы
  5. Включите «Авто-пауза при риске» для безопасности
  6. Нажмите «Запустить прогрев» — AI работает 24/7
  7. Дождитесь достижения trust-score 80%+ (обычно 3-7 дней)
4

Нейрокомментинг

AI-генерация комментариев под постами для привлечения аудитории.

GPT-4o Cerebras
  1. Убедитесь что аккаунты прогреты (trust-score 80%+)
  2. Откройте модуль «Нейрокомментинг»
  3. Введите целевые каналы через запятую
  4. Выберите тон: Экспертный / Дружелюбный / Провокационный
  5. Выберите модель: GPT-4o (качество) или GPT-4o-mini (скорость)
  6. Настройте частоту: каждый пост / каждый 2-й / каждый 5-й
  7. Нажмите «Запустить» — AI генерирует и публикует комментарии
  8. Мониторьте лог активности в реальном времени
5

Нейрочаттинг

AI-ответы в группах и чатах для конвертации лидов.

AI-воронки 500+ сценариев
  1. Добавьте целевые группы в модуле «Нейрочаттинг»
  2. Выберите стратегию: Эксперт / Networking / Промо / Вопросы
  3. Включите «Возражения» для отработки 500+ сценариев
  4. Включите «Urgency + Social Proof» для повышения конверсии
  5. Настройте лимит сообщений в час (рекомендуется 10)
  6. Установите задержку между сообщениями (2-5 мин)
  7. Запустите и мониторьте активные диалоги
6

НейроДиалоги (AI-воронки)

Автоматические ЛС с AI-ведением воронки продаж.

Автоматизация CRM
  1. Настройте воронку: Первый контакт → Прогрев → Предложение → Закрытие
  2. Выберите сценарий под вашу нишу (крипто, e-commerce, SaaS)
  3. Настройте тексты сообщений для каждого шага воронки
  4. Включите A/B тестирование для оптимизации
  5. Запустите воронку — AI ведёт диалоги автоматически
  6. Отслеживайте конверсию в CRM
7

Anti-Ban Shield

Настройка максимальной защиты аккаунтов от блокировок.

Безопасность 24/7
  1. Проверьте статус Shield на главной странице
  2. Убедитесь что все компоненты активны: Typing Emulation, Activity Schedule, Random Delays, Device Fingerprint, Read Simulation
  3. Настройте прокси: IPv4/SOCKS5 с ротацией
  4. Включите «Авто-пауза при риске» во всех модулях
  5. Мониторьте Risk Score и Human-Like метрику
  6. При получении Flood Wait — AI автоматически делает паузу

Автоматические реакции на посты с AI-подбором эмодзи.

Эмоциональный маппинг
